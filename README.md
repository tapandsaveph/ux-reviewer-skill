# UX Reviewer Skill

This repository contains the CloudSkills UI/UX reviewer package for Codex.

## Skill Entrypoint

- `skills/ux-reviewer/SKILL.md`

## Included Support Files

- `frameworks/` - workflow, severity, cognitive load, source-of-truth, risk, and production-safety review frameworks
- `patterns/` - reusable UX review patterns for forms, dashboards, tables, queues, approvals, settings, search, filtering, and error states
- `lenses/` - optional review perspectives for accessibility, mobile, enterprise, consumer, engagement, trust, AI experience, and visual design
- `test-cases/` - sample scenarios for validating the reviewer

The reviewer skill routes to these support files by relative path, so they are kept together in this package.
