# Long Signup Form

A new user must fill 22 fields before seeing the product: name, email, phone, company size, industry, team goals, billing address, tax ID, role, invite list, integrations, and marketing source. Validation runs only after submit and clears two fields on error.

Problems the skill should identify:
- unnecessary upfront fields
- missing progressive disclosure
- late validation
- data loss after error
- poor mobile and keyboard ergonomics
- unclear what happens after signup
