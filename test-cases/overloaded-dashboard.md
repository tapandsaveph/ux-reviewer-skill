# Overloaded Dashboard

A customer success manager opens the home dashboard after login. It shows 14 charts, recent activity, MRR, usage graphs, NPS, all accounts, and a news feed. The manager's real job is to find accounts that need action today.

Problems the skill should identify:
- unclear primary action
- dashboard used where task queue is likely better
- too many choices
- weak hierarchy
- missing owner/status/blocker prioritization
- metrics not tied to decisions
