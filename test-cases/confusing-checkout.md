# Confusing Checkout

A buyer reviews a checkout page with two primary-looking buttons: "Continue" and "Activate". Taxes appear after payment submission. A promo code error appears in a toast. The cancel link sits next to the purchase button. The order summary does not show renewal terms.

Problems the skill should identify:
- unclear primary action
- hidden cost and renewal consequences
- unsafe destructive/cancel action placement
- validation feedback detached from field
- missing success/error states
- trust and mistake-prevention issues
